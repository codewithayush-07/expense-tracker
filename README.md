# 💰 Expense Tracker

A modern, responsive **Expense Tracker Web Application** built using HTML, CSS, and JavaScript. This project helps users manage their personal finances by tracking income, expenses, and balance through a simple and interactive interface.

## ✨ Features

- 💵 **Income Tracking** – Record and manage your income.
- 💸 **Expense Tracking** – Add and monitor daily expenses.
- 📊 **Balance Overview** – View total income, expenses, and remaining balance.
- 📝 **Transaction Management** – Add, edit, and delete transactions.
- 🔍 **Search & Filter** – Find transactions and filter them by category or type.
- 🌙 **Dark Mode** – Switch between light and dark themes.
- 📈 **Financial Charts** – Visualize financial activity with charts.
- 💾 **Local Storage** – Save transaction data in your browser.
- 📱 **Responsive Design** – Works across desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser Local Storage

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/codewithayush-07/expense-tracker.git
```

### 2. Navigate to the Project Folder

```bash
cd expense-tracker
```

### 3. Run the Application

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No additional installation or database setup is required.

## 💾 Data Storage

The application uses browser Local Storage to retain transaction data between sessions. Data is stored locally in the browser and is not automatically synchronized across devices.
